## The entry

> I died doing what I loved: avoiding my responsibilities.

One line, 56 characters — a tombstone epitaph of famous last words. It twists
the classic carved-in-stone line "died doing what he loved" into a confession:
the thing he loved most was dodging every responsibility, and death finally
caught up with the one chore he could never outrun.

## How it works

`main.py` writes the epitaph to the entry output: `$ENTRY_OUT` when set as a
file, otherwise `$ENTRY_OUT_DIR/entry.txt`, otherwise `/output/entry.txt`.
The text is validated in code — a single line, 1–150 characters, UTF-8, no
trailing newline — and is byte-identical on every run.

Run it:

```sh
python3 main.py
```
